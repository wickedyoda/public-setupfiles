# bypass_sites.txt Index

> Index of categorized domains in [`bypass_sites.txt`](./bypass_sites.txt)

## Overview
This file is the combined bypass list for Pi-hole / VPN proxying.  
It is regenerated by [`updater/update_domains.py`](../updater/update_domains.py) —  
it appends only, never deletes existing entries.

**Streaming services are intentionally excluded** (Netflix, Hulu, Disney+, etc.).  
See [`streaming_domains_whitelist.txt`](./streaming_domains_whitelist.txt) for those.

## Structure
- Lines beginning with `#` are section headers or comments — preserved on update.
- Bare domains are matched case-insensitively and de-duplicated.
- CIDR blocks (`/xx`) are treated as IP ranges, not domains.
- Blank lines separate visual sections only.
